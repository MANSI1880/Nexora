# Software Access Request

## Issue
User needs a new application installed on their work machine.

## Troubleshooting Steps
1. Check if the software is in the Approved Software Catalog (e.g., Microsoft Office, VS Code, Slack).
2. If approved, direct the user to the self-service Software Center to install without admin rights.
3. If not approved, the user must submit a Software Exception Request.

## Escalation
Software Exception Requests require Manager approval and Security Team review.
