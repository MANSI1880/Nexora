# VPN Troubleshooting Guide

## Issue
User cannot connect to the enterprise VPN.

## Symptoms
- "Authentication failed" error
- Connection timeout
- Cisco AnyConnect hangs

## Possible Causes
- Expired password
- Outdated VPN client
- Internet connection drop

## Troubleshooting Steps
1. Verify internet connection is active.
2. Check if the password has expired.
3. Restart Cisco AnyConnect.
4. Clear the AnyConnect cache.

## Escalation
If the issue persists after steps 1-4, create a High priority ticket for the Network Team.

## Warnings
Do not bypass the MFA requirement when connecting.
