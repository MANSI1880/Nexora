# Password Reset Guide

## Issue
User forgot their Active Directory password or is locked out.

## Symptoms
- "Invalid credentials" error
- "Account locked" error

## Troubleshooting Steps
1. Navigate to the self-service portal at `https://password.nexora.internal`.
2. Answer the security questions or use the SMS OTP.
3. Choose a new password that meets the 12-character requirement.

## Escalation
If the user cannot access the self-service portal, the Helpdesk must perform identity verification via video call before manually resetting.
